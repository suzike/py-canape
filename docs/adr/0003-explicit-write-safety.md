# ADR-0003：写操作必须经过显式安全策略

## 状态

Accepted

## 背景

标定、内存写入、下载、诊断和刷写可能影响 ECU 或车辆安全。仅靠调用者自律不能满足
无人值守工作流和跨专业复用需求。

## 决策

引入 `SafetyPolicy`。所有自动编排的写操作必须声明权限级别、目标白名单、数值或地址
范围以及车辆前置条件；默认策略只允许只读。凭据只通过外部 `SecretProvider` 获取。

## 后果

### 正面

- 默认安全失败；
- Dry-run 和审计能展示实际写入；
- 车型约束由配置扩展而非写死。

### 负面

- 写操作需要更多配置；
- 直接调用底层 COM 类仍需调用者负责，文档必须明确。

## 备选方案

- 在每个方法中写死门禁：拒绝，无法适配不同车型；
- 默认允许全部写入：拒绝，风险不可接受。
