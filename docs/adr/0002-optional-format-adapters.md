# ADR-0002：文件格式使用可选适配器

## 状态

Accepted

## 背景

MDF/MF4、BLF/DBC、Word/Excel 等格式依赖不同第三方库，部分库可能暂不支持最新
Python。强制安装全部依赖会让仅使用 COM 的用户也承担冲突。

## 决策

基础包只依赖 PyYAML；数据、报告和 Vector 文件解析放入 extras。运行时按格式延迟
导入并在缺失时报告准确的 extra 名称。CSV/JSON/Parquet 使用通用适配器。

## 后果

### 正面

- 基础安装稳定；
- 格式能力可以独立升级；
- 测试可以用内存表和 CSV 完成。

### 负面

- 某些能力首次使用前需要安装 extra；
- 必须维护清晰的依赖错误信息。

## 备选方案

- 强制安装所有依赖：拒绝，兼容性和安装体积不可控；
- 自行实现完整 MDF/BLF：拒绝，格式复杂且已有成熟库。
